Colores semánticos

Cada color tiene tres tokens. El de base es el fondo de los elementos sólidos; -content, el texto sobre ese fondo; -text, el color para texto, íconos y bordes sobre la página. El contraste de -content se mide contra su color y el de -text, contra base-100.
